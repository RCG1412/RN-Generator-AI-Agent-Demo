# RN-Generator-AI-Agent-Demo

AI-powered documentation pipeline that reads Jira, writes docs, checks quality, and deploys to a live website.

## Quick Start

1. Run setup: `.\Agents\setup\setup-windows.ps1` (or `.sh` for Mac/Linux)
2. Open in Claude Code and type: `/doc-writer for Version 1.2`
